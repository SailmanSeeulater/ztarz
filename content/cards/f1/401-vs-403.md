tags: ["http", "auth"]
choices:
  - text: "401 is a client error; 403 is a server error"
    why: "Both are 4xx client errors. Server errors are 5xx."
  - text: "403 means the resource doesn't exist"
    why: "That's 404. Some APIs do answer 404 instead of 403 so they don't reveal that the resource exists."
  - text: "They're interchangeable"
    why: "Clients act differently: a 401 should send you to sign in; a 403 shouldn't."
  - text: "401: we don't know who you are; 403: we know, and you're not allowed"
    correct: true
    why: "401 means missing or invalid credentials, so signing in again can fix it. 403 means authenticated but not authorized, and signing in again won't help."

## Prompt

An API returns 401 for one request and 403 for another. What's the difference?
