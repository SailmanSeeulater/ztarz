## Prompt

What's the difference between `Cargo.toml` and `Cargo.lock`, and should you commit the lock file?

## Answer

- **`Cargo.toml`** is written by you: the package name and version, and dependencies with loose version requirements such as `serde = "1.0"`.
- **`Cargo.lock`** is generated by Cargo: the exact version (and source) of every dependency it resolved, including transitive ones.

With the lock file, everyone who builds the project gets the same dependency versions. `cargo update` deliberately moves them forward and rewrites the lock file. When in doubt, commit `Cargo.lock` to version control.
